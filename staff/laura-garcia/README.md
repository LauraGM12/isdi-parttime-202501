# 📌 Comandos Básicos de Terminal y Git
## 📂 Navegación y Gestión de Archivos en la Terminal
- **`ls`** → Lista todas las carpetas y archivos del directorio actual.
  - Ejemplo:
    ```sh
    ls
    ```
- **`cd <nombre-carpeta>`** → Entra en una carpeta específica.
  - Ejemplo:
    ```sh
    cd documentos
    ```
- **`cd ..`** → Retrocede un nivel en el directorio.
  - Ejemplo:
    ```sh
    cd ..
    ```
- **`mkdir <nombre-carpeta>`** → Crea una nueva carpeta.
  - Ejemplo:
    ```sh
    mkdir nueva_carpeta
    ```
- **Eliminar una carpeta:**  
  ```sh
  rm -r <nombre de la carpeta>
